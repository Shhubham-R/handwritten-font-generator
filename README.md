# Handwritten Font Generator

A simple static font preview website hosted on GitHub Pages.

This project lets you:
- preview handwriting-style fonts directly in the browser
- choose from bundled fonts in this repository
- upload your own local font files and test them instantly
- type custom text and see the result live

## Live site

https://shhubham-r.github.io/handwritten-font-generator/

## About

This repo is similar in spirit to:
- https://github.com/Shhubham-R/hub-motor-calculator

Just like that project, this one is meant to be a lightweight tool that runs fully on GitHub-hosted static pages.

## Create your own fonts

If you want to create handwritten fonts for use with this preview tool, use this repo:
- https://github.com/Shhubham-R/handwritten-font-generator-Stochastic-text-rendering

## Tech

- plain static HTML/CSS/JavaScript
- GitHub Pages for hosting
- no backend required

## Repository purpose

This repository is focused on one thing:
previewing existing or uploaded font files in a simple browser interface.
